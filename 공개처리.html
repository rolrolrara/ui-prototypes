게시글 공개/비공개 처리 개선 — 프로토타입
친구들의 캐츠 활용기 게시판의 공개 처리 업무를 화면에서 끝내기 위한 두 방향입니다. 두 방향은 택일이 아니라 함께 제공될 수 있으며, 실제 동작을 눌러보며 확인할 수 있습니다.
A안

상세에서 바로 공개 처리 + 이전/다음 연속 검수

현재는 상세에서 공개여부가 읽기 전용이라 수정 버튼을 눌러 수정 모드로 들어가야 바꿀 수 있습니다. 공개하기 체크박스를 수정 모드 밖으로 꺼내 상세 화면에서 체크 즉시 적용되게 하고, 이전 글/다음 글 버튼으로 글을 넘기며 연속으로 검수합니다.

검수 동선: 글 읽기 → 공개하기 체크(즉시 적용) → 다음 글 → 반복
B안

목록 다중 선택 → 일괄 공개/비공개

목록에 체크박스와 전체 선택 · 전체 해제 버튼을 추가하고, 선택한 글을 한 번에 공개/비공개 처리합니다. 제목에 마우스를 올리면 내용 미리보기가 떠서 목록에서 바로 검수할 수 있습니다.

검수 동선: 검색으로 대상 좁히기 → 전체 선택 후 문제 글만 체크 해제 → 일괄 공개
C안

목록 일괄 처리 — 실화면 기준 간소형

실제 게시판관리 화면 구성을 그대로 유지한 채 체크박스만 추가하고, 목록 우측 상단에 "✓ 선택한 회원에 대해 [선택 공개] [선택 비공개]" 버튼을 배치한 안. 엑셀 다운로드 버튼은 총 N개 바로 옆, 기간·작성자(회원번호) 검색이 함께 추가됩니다.

검수 동선: 기간·회원번호로 검색 → 대상 글 체크 → 선택 공개/비공개
· 일괄 처리 시점에 이미 삭제된 글은 자동 제외되고 결과가 안내됩니다 (B안에서 시연 가능 — 감옥에서 누가돌아왔게~~~ 글이 삭제된 상황을 가정).
· 공지글(관리자 작성)은 일괄 처리 대상에서 제외되어 체크박스가 비활성화됩니다.
